与EVSSM类似 此论文的核心创新点也是扫描路径上的创新

DefMamba的核心创新是将可形变机制应用于mamba上并作出部分修改

可形变机制

在文章中这个概念来自于《Deformable Convolutional Networks》一文，在此文章中提出了一种可形变卷积的概念，传统的卷积操作是按照格栅扫描的顺序逐个全遍历，而可形变卷积是在原卷积操作点的基础上进行偏移变形，使卷积网络可以更加关注“应该”关注的地方

在计算上表示，首先先定义一个规则网络，输入特征图x，输出特征图y，求和权重w。

对于常规的二维卷积有，对于在y上的任意位置p0有 y(p0) = ∑pi ∈ Rw(pi) ⋅ x(p0 + pi)。

可形变卷积使用偏移{Δpi|i = 1, ..., N}来增强这部分计算，其中N = |R|。 上面式子可变为 y(p0) = ∑pi ∈ Rw(pi) ⋅ x(p0 + pi + Δpi)

由于修改后的pi + Δpi可能并非是整数，所以上述式子通常使用双线插值法实现，有x(p) = ∑qG(q, p) ⋅ x(q)。其中p表示x中任意位置，q表示枚举积分空间中所有位置，G(,)是双线性插值核且是二维的，故有G(q, p) = g(qx, px) ⋅ g(qy, py)，其中g(a, b) = max(0.1 − |a − b|)。

双线性插值法

简单来说 就是在离散值之间插入一个估计值，假设存在点(x1, y1), (x2, y2)要在它俩之间插入一个估计值(x, y) 根据线性插值就有。但这种单个维度的线性插值只利用了两个点，误差较大。所以在图像的处理中多数用双线性插值法。双线性插值是在两个维度上进行插值操作，假设存在四个点Q1, 1, Q1, 2, Q2, 1, Q2, 2，先让Q1, 1，Q2, 1和Q1, 2，Q2, 2 两两一组进行线性插值得到R1, R2再使用R1, R2进行线性插值得到估计点P。详细解释可见双线性插值(Bilinear Interpol)原理及应用

Defmamba就是将这种可形变机制迁移到vision mamba的扫描机制上。具体来讲就是在分好的patch上给出参考点和参考token，与偏移矩阵与输入特征图计算后得到偏移量，将偏移量作用在参考点和参考token上得到点偏移和token偏移。点偏移表明图像更关注这个token或者说patch的哪个地方，token偏移则是改变patch排列顺序即改变mamba的扫描顺序。

整个DefMamba的结构使用了与Transformer的only-decoder架构类似的多尺度骨干结构，分为四个阶段逐层下采样。在每个阶段内部的Deformable Mamba Block 中核心的就是DSSM部分，DSSM部分在保留了Vim 中Vision Mamba Encoder大部分的结构的情况下引入一个包含可变形扫描和可变形SSM (DSSM) 的可变形分支，并且用Dconv来替换掉Vim中原始的1D卷积。 保留Vim正向和反向分支的目的是为了确保模型稳定收敛。
