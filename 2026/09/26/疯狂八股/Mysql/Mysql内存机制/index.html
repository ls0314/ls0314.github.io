Mysql内存机制

发表于 2026-09-26 分类于 疯狂八股 ， Mysql 阅读次数： 本文字数： 1.9k 阅读时长 ≈ 3 分钟

MySQL的内存常指的就是Buffer Pool，在之前了解redo log的持久化过程时，有提到过redo log会根据参数的来决定当前的redo记录是先暂存在Buffer Pool里redo buffer pool 还是写入Os 的Page Cache 或是直接刷入磁盘。所以为啥MySQL为什么需要Buffer Pool呢?

1.Buffer Pool

了解MySQL的架构可以知道MySQL存储的数据是放在磁盘内的，大量的I/O会因为磁盘速度的现在导致性能极差。所以想要提升这个性能最简单粗暴的方式就是在架构中加一个缓存，当数据从磁盘中取出是会缓存在内存中当下一次查询同一个数据时就可以直接从内存中获取。因此InnoDB存储引擎设计了一个缓冲池，来提高数据库的读写性能。

当有了缓存池后：

  • 读取数据时，InnoDB会优先读取Buffer Pool中的数据，若不存在才会取磁盘中读取
  • 当修改数据时，InnoDB会先将要修改的数据所在页拉到Buffer Pool内，修改对应数据后将其标记为脏页，最后由后台线程决定什么时候将脏页写入磁盘。

Buffer Pool内部结构

因为InnoDB会将存储的数据划分为页（默认大小为16KB），以页来作为磁盘和内存交互的基本单位，所以Buffer Pool也以需要按页划分。在MySQL启动时InnoDB会为Buffer Pool申请一片连续的内存（默认128MB），之后按照默认的16KB的大小划分为页，每一个都叫做缓存页。这些缓存页随着用途不同可能会有不同的别名，如存储数据或脏页的数据页、存储索引的索引页还有如插入缓存页、undo页、自适应哈希索引和锁信息等。

Buffer Pool管理机制

  1. 管理空闲页

    Buffer Pool是一片连续的内存，当经过一段时间的使用后这片内存空间可能有的被使用有的仍处于空闲，但我们要是想从磁盘读数据放入内存线性查找空闲内存显然是不合理的，所以为了快速查找空闲的缓存页，InnoDB选择舍弃部分内存用来存储控制块每一个控制块都对应的指向一个空闲的缓存页。所有用来指向空闲缓存页的控制块（还有指向其他类型缓存页的）组成一个Free链表，这样就可以按照链表逐个取用空闲缓存。

  2. 管理脏页

    除了上述的Free控制块链表Buffer Pool还有针对脏页的Flush链表，与Free类似Flush链表内的每一个控制块指向一个脏页（数据页），这样就可以方便后台线程快速将脏页写入磁盘。

  3. 提高缓存命中率

    Buffer Pool大小是有限的，我们希望保存在里面的数据最好都是必要的和常用的，对于可能仅使用一次或几次的数据最好在淘汰内存是有限淘汰掉。为了实现这个机制很自然的就可以想到LRU（最近最少使用）淘汰机制，这个机制经常出现在缓存淘汰的场景里，其大致意思是每当要发生缓存淘汰时我们希望被淘汰的是最久未用的数据页。但简单的LRU算法无法解决预读失效和Buffer Pool污染问题。

    预读机制是MySQL认为靠近当前被访问数据的数据，在未来很大概率也会被访问，所以就会跟着被访问的数据页一并加载到内存里以减少I/O次数

    Buffer Pool污染是指，若执行了全量扫描导致大量的数据要进入Buffer Pool可能导致整个LRU队列的数据要全部替换一次这可能会将大量的热点数据给替换掉，当数据库再次查询这些热点数据时由于缓存未命中就会产生大量磁盘I/O。

    针对预读失效问题InnoDB将LRU的队列按3：5的比例划分为old和young区域，每次被访问的数据会正常进入young区域但预读进来数据会进入old区域，这样如果预读一直未使用也会很快被淘汰。

    针对Buffer Pool污染问题InnoDB对进入young区域的条件进行了一下处理从被访问变成被访问且在old区域停留超过x秒（默认为1s）只有这样的节点才可以被插入young区域（因为热点数据都在young里，提高插入条件就会减少热点数据被淘汰到old区域的几率）。

  4. 脏页刷入磁盘的机制

    因为为了提高数据库的读写效率，所修改的数据不会第一时间写回磁盘而是存储在Buffer Pool的脏页内，所脏页在何时何种条件会刷会磁盘也是值得思考的问题，既要保证数据的安全又不能太影响读写效率。

    InnoDB中下面几种情况会触发脏页的刷新：

    • 当redo log日志满了，会主动触发脏页刷新到磁盘
    • Buffer Pool空间不足时如果淘汰的数据页是脏页，会先将脏页刷入磁盘再淘汰
    • MySQL认为当前空闲时后台线程会定期的将适量脏页刷入磁盘
    • MySQL正常关闭前会把所有脏页刷入磁盘

总结一下InnoDB设计了Buffer Pool主要就是为了提升读写性能，为了更好的提升性能又设计了一套管理方法。
